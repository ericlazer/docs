Nexio provides an open integration layer that lets developers, auditors, and custodians interact directly with Series, vaults, and event data.

This section explains how to connect to Nexio’s smart contracts, read real-time state, and build applications that visualize or reconcile BTC activity on-chain.

If you are looking to start building, [reach out to the team on Discord.](https://discord.com/invite/nexio)

### **Developer Architectures**

All programmatic access routes through two primary components:

1. **Operator Contracts (on-chain)**: Manage proposals, Series logic, and vault state.
2. **Data API (off-chain)**: Provides indexed, developer-friendly access to blockchain data for dashboards and accounting systems.

Together, these layers expose deterministic, verifiable data that mirrors Bitcoin custody.
